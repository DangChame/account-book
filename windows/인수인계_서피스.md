## 2. 이번 세션에서 고친 것 (커밋됨)
- `naver.js`: 끝에 `process.exit(0)` — CDP 연결이 열려 있어 node가 안 끝나던 문제
- `coupang_parse.py`: json을 `encoding="utf-8"`로 읽음 (윈도우 기본 cp949에서 실패)
- `windows/run_daily.ps1`: `PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8`, `[Console]::OutputEncoding=UTF8`, `ASIDE_CDP` 기본값
- `windows/register_task.ps1`: `-WindowStyle Hidden` (첫 시험 실행이 콘솔 창이 닫히며 0xC000013A로 끝났음)
- `.ps1` 파일 전부 **UTF-8 BOM**으로 저장 (Windows PowerShell 5.1이 BOM 없으면 한글 작업 이름을 깨뜨려 등록 실패). `.ps1`을 고치면 BOM 유지할 것

## 4. Surface에서 처음 할 설정
1. 저장소를 같은 경로(`C:\Users\<사용자>\Desktop\account_book\account-book`)에 받고 브랜치 체크아웃 → `CLAUDE.md`, `windows/SETUP.md`, 이 문서 읽기
2. `powershell -ExecutionPolicy Bypass -File windows\setup.ps1` (SETUP.md 참고). Aside 모드에선 Playwright 크로미움 다운로드가 실패해도 무방
3. 비밀 파일: 데스크톱 `%USERPROFILE%\.config\ledger\`를 통째로 Surface 같은 위치로 복사 (`token.json`, `telegram.json`, `naver_state.json`, `*_done.json`, `eats_pending.json`, `naver_out\`, `daily.log`). 옮긴 뒤 `python ledger.py rget 26-11 A3:A3`로 OneDrive 확인. 실패하면 SETUP.md의 OneDrive 재로그인 절차
4. Aside: Surface에 Aside 설치·네이버 로그인(사용자가 직접) → Aside를 `--remote-debugging-port=9222`로 실행 → `http://127.0.0.1:9222/json/version` 응답 확인
   - 실행 중인 Aside는 포트 없이 떠 있으면 한 번 종료 후 옵션으로 다시 켜야 함 (사용자 창이 닫힘을 알릴 것)
   - 사용자 환경변수 `ASIDE_CDP=http://127.0.0.1:9222`
   - 자동 실행: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 값 `AsideDebug` = `"C:\Program Files\Aside\Application\Aside.exe" --remote-debugging-port=9222` (사용자 승인 받고 등록. 설치 경로는 Surface에서 확인)
5. `claude` CLI 로그인: PowerShell에서 `claude` → `/login` (사용자가 직접). 데스크톱 앱 로그인과 공유 안 됨. 확인: `claude -p "ok"`
6. `powershell -ExecutionPolicy Bypass -File windows\register_task.ps1`
7. 데스크톱 쪽 작업 비활성화 (1장 참고)
8. Surface 절전/덮개 닫힘 시 깨우기: 작업에 WakeToRun이 있지만 Surface(Modern Standby)에서 실제로 깨는지는 확인 못 함 → 전원 설정에서 "절전 모드 해제 타이머 허용" 확인 권장
