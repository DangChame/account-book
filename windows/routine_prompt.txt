[가계부 새벽 수집 2단계] collect.py가 네이버 수집·중복 확인·포인트·새 달 파일을 이미 끝냈다. 네이버 수집 명령(naver.js)은 다시 돌리지 않는다.
~/.config/ledger/collect_todo.json 의 items 만 처리해라 (auto는 이미 끝난 일, 보고용).
1) 각 건을 CLAUDE.md '기록 규칙'대로 분류. 같은 결제가 여러 건(출처)으로 있으면 날짜·금액으로 짝지어 한 번만 기록.
2) python ..\ledger-web\tools\book.py get YY-MM <범위> 로 빈칸 확인 후 book.py set 으로 기록 (취소 건은 해당 칸 지우기).
3) 기록했거나 기록할 필요 없는 건: python collect.py done <key>...   애매해서 사용자에게 묻는 건: python collect.py ask <key>... (기록하지 않음)
   key가 eats인 건은 맞는 주문이면 사유를 고치고 ~/.config/ledger/eats_pending.json 에서 그 항목을 뺀다.
4) python tg.py "..." 로 짧게 보고: 기록한 것(날짜·칸·금액·사유), 질문, auto 중 '이미 있음'이 아닌 것.
git 명령은 쓰지 않는다 (실행 스크립트가 끝나고 올린다).
