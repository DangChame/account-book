# 참고: 수집 명령·데이터 형식·엑셀·로그인 (필요할 때만 읽기)

CLAUDE.md에서 옮긴 자세한 내용. 평소 새벽 수집은 `collect.py`가 이 일을 다 하므로 Claude가 직접 돌릴 일은 드물다.

## 네이버페이(머니카드)
- `node naver.js history` → `~/.config/ledger/naver_out/api.json` (`paymoneyList`: PAYDTTM, PAYAMT, FILTER use/charge, TYPE nfc=머니카드·pmuse=페이결제·pmcancel=취소, TITLE=가맹점)
- `charge`(저축 계좌에서 충전)는 지출 아님. 가승인/취소 쌍은 제외. PAYAMT는 머니 차감액(포인트분 제외).
- 포인트: `node naver.js points 20261101 20261130` → naver_out/points.json (tradeAmount 양수=적립, 음수=사용). 처리한 PAYSEQ는 `~/.config/ledger/naver_done.json`.

## 국민·신한카드 문자 (메일 방식)
- 아이폰 단축어 자동화: 문자에 '국민카드' 포함 → '메일 보내기'(받는 사람 본인 네이버 메일, 제목 `[국민카드 문자]`, 본문=단축어 입력, 작성 시트 끔). 신한카드 문자도 같은 제목으로 온다.
- `node naver.js kbmail` → naver_out/kbmail.json (mailSN, time(초), body). 제목이 `[국민카드 문자]`인 메일만 읽는다. 처리한 mailSN은 `kbmail_done.json`.
- (OneDrive 파일 방식은 iOS에서 OneDrive 폴더 선택 불가로 폐기)

## 엄마카드(NH) 화면 메일
- 사용자가 농협카드 이용내역 화면에서 폰 뒷면 두 번 탭 → 단축어(스크린샷→텍스트 추출→메일, 제목 `[농협카드 화면]`).
- `node naver.js kbmail '[농협카드 화면]' nhmail` → naver_out/nhmail.json. OCR 텍스트에서 가맹점/날짜는 위에, 금액(`12,890원>`)은 아래에 같은 순서로 나온다 → 순서대로 짝짓기 (`collect.py`의 `nh_items`). 처리한 mailSN은 `nhmail_done.json`.

## 쿠팡·결제대행사 영수증
- 쿠팡 사이트는 해외 데이터센터 IP를 403으로 차단 → 접속 불가(우회 금지). 메일로 처리.
- `node naver.js kbmail '쿠팡(주)' coupang_pg` + `node naver.js kbmail 'NHN KCP' pg_kcp` + `node naver.js kbmail '결제하신 내역' pg_kicc` → `python coupang_parse.py pg YYYYMM` (세 파일 합쳐 mailSN 중복 제거; 결제시각·금액·카드·가맹점·상품명, 취소/부분취소 표시). NHN KCP '카드종류' / KICC 이지페이 '결제기관' 두 형식.
- 주문 상세: `node naver.js kbmail '주문하신 내역을 확인해주세요' coupang` → `python coupang_parse.py 202611` (쿠팡이츠 주문 메일도 같은 제목, `[쿠팡이츠]` 접두).
- 메일 검색 결과에 다른 메일이 섞일 수 있으니 결제 문구가 있는 것만 사용. 처리한 영수증 mailSN은 `coupang_pg_done.json`(모든 영수증 공용).

## 네이버쇼핑 결제 상품명
- `node naver.js payhist 2` → naver_out/payhist.json (id, date(ms), merchant, product, price, rest, method CREDIT_CARD 등, status). 처리한 id는 `payhist_done.json`.

## 네이버 로그인
- 윈도우: naver.js가 `ASIDE_CDP=http://127.0.0.1:9222`로 Aside 브라우저에 붙어 그 로그인을 쓴다. 대안 `node naver.js loginlocal`.
- **아이디·비밀번호 자동 로그인 금지** (`loginpw` 쓰지 않음): 2026-11-12 해외 IP 보안문자 반복으로 아이디 보호(잠금)까지 걸렸다. 일회용 번호 로그인은 1.5일이면 만료.
- (클라우드 전용) 쿠키 가져오기: 사용자가 PC 크롬에서 '로그인 상태 유지' 켜고 'IP 보안' 끈 채 로그인 → NID_AUT, NID_SES 값을 OneDrive `가계부/naver_cookie.txt`에 → `~/.config/ledger/naver_state.json`에 저장 → `node naver.js history`로 확인 → OneDrive 파일 삭제.
- 보안확인 사진 등 사용자에게 보여줄 이미지는 Claude 대화창으로(텔레그램 금지).
